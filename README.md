# ChosuTab Edit

## 概要
新しいタブページを簡易的にカスタマイズするChrome拡張です。

## インストール方法
1. ダウンロードしたzipふぁいるを展開
2. 拡張機能を管理を開く
3. デベロッパーモードをオンにし、パッケージ化されていない拡張機能を読み込むを押す
4. ファイル選択で中にmmanifest.jsonが入っている状態でおいてあるChosutabEditを開く

## 使い方
1. 拡張機能を管理 or ツールバーの拡張機能からオプションを開く
2. ご自由に設定をカスタマイズ
3. (ショートカットのカスタマイズの場合は)下の保存ボタンを押す
4. 保存が完了したら、新しいタブを開く

## 注意
- ショートカットURLは http:// または https:// から入力してください。
- この拡張機能はアーリーアクセス版であることにご留意ください。正式リリース時にバックアップのJsonの互換性が失われたり、UIに大きな変更が入る可能性があります。
- 最小動作サイズは1480 x 515です。最小動作サイズ未満ですとレイアウトが崩れます。
- ショートカットの内容を変更する際は更新が必要(今後更新は不要になるかも)
